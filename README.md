### 🎯 Acerca de Este Repositorio
Este repositorio contiene una serie de ejercicios que demuestran el uso de estructuras iterativas en C++. Cada programa resuelve un problema común mediante el uso de bucles `for`, `while` y `do-while`, facilitando así la comprensión de la programación iterativa.

---

### 📋 Lista de Ejercicios

1️⃣ **Tabla de Multiplicación**  
   **Descripción:** Muestra la tabla de multiplicación de un número ingresado.  
   **Entrada:** Un número entero.  
   **Salida:** La tabla de multiplicación de ese número del 1 al 10.  
   **Concepto:** Utiliza un bucle `for`.

---

2️⃣ **Números Impares**  
   **Descripción:** Imprime todos los números impares desde 1 hasta el número ingresado.  
   **Entrada:** Un número entero.  
   **Salida:** Todos los números impares hasta el número ingresado.  
   **Concepto:** Utiliza un bucle `for`.

---

3️⃣ **Cálculo del Factorial**  
   **Descripción:** Calcula el factorial de un número entero ingresado.  
   **Entrada:** Un número entero.  
   **Salida:** El factorial de ese número.  
   **Concepto:** Uso de un bucle `while`. Los números negativos no se permiten.

---

4️⃣ **Potencia de un Número**  
   **Descripción:** Calcula la potencia de una base elevada a un exponente dado.  
   **Entrada:** Base y exponente.  
   **Salida:** El resultado de la potencia.  
   **Concepto:** Emplea un bucle `while` para el cálculo.

---

5️⃣ **Doble y Triple de un Número**  
   **Descripción:** Solicita un número repetidamente y calcula su doble y su triple.  
   **Entrada:** Un número entero.  
   **Salida:** Doble y triple del número.  
   **Concepto:** Utiliza la estructura `do-while`.

---

### 💡 Conceptos Importantes

| Concepto               | Descripción                                          |
|------------------------|------------------------------------------------------|
| **Bucle `for`**        | Iteración fija basada en un contador.                |
| **Bucle `while`**      | Iteración basada en una condición booleana.          |
| **Estructura `do-while`** | Similar al bucle `while`, pero garantiza al menos una ejecución. |
| **Factorial**          | Producto de todos los enteros positivos hasta el número dado. |
| **Potencia**           | Resultado de multiplicar una base por sí misma repetidamente. |
